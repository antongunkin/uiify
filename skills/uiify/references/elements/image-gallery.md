# image-gallery

Binding: gap

Show related images with useful captions or alternatives.

Represent a gallery as a list of figures. Give each image an alternative that conveys its content and use a caption when the surrounding text needs context.

```html
<ul>
  <li><figure><img src="/place.webp" width="640" height="400" alt="Stone bridge over a river" /><figcaption>Old town bridge</figcaption></figure></li>
</ul>
```

This is an app-level composition recipe; it does not add a component to UIify.
