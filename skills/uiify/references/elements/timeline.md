# timeline

Binding: gap

Show dated events in chronological order.

Use an ordered list when sequence matters. Encode machine-readable dates with time and keep each event’s date attached to its description.

```html
<ol>
  <li><time datetime="2026-10-16">October 16, 2026</time><p>Release published</p></li>
</ol>
```

This is an app-level composition recipe; it does not add a component to UIify.
