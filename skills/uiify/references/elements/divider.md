# divider

Binding: gap

Separate adjacent thematic sections when a heading is not appropriate.

Use a thematic separator only when it marks a real change of topic; leave purely decorative separators out of the accessibility tree.

```html
<hr />
```

This is an app-level composition recipe; it does not add a component to UIify.
