# code-block

Binding: gap

Present source text with preserved whitespace.

Use preformatted code with a concise caption. Preserve whitespace and provide a separate, clearly named copy action only when copying is available.

```html
<figure>
  <figcaption>Install the package</figcaption>
  <pre><code>npm install uiify</code></pre>
</figure>
```

This is an app-level composition recipe; it does not add a component to UIify.
