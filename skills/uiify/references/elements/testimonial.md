# testimonial

Binding: gap

Attribute a customer quote to a named source.

Use a quotation with a clear attribution. Include the speaker and relevant affiliation in text when the quotation needs that context.

```html
<figure>
  <blockquote><p>Setup took minutes.</p></blockquote>
  <figcaption>— Ada Lovelace, Acme</figcaption>
</figure>
```

This is an app-level composition recipe; it does not add a component to UIify.
