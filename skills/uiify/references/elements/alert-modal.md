# alert-modal

Binding: alert-modal

Confirm an irreversible action before executing it.

Explain the consequence before asking for a decision. Give the dialog a clear title, keep the safe action available, and return focus after the choice.

Related laws: references/laws/error-prevention.md, references/laws/accessibility.md
