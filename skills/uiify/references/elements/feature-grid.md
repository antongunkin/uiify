# feature-grid

Binding: gap

Present related product capabilities as a coherent set.

Use a repeated grid when the features share the same level and structure. Keep each feature’s heading and explanation in reading order at narrow widths.

Related laws: references/laws/proximity.md, references/laws/readability.md
