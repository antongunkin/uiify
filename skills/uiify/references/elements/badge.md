# badge

Binding: gap

Mark a short status or category beside related content.

Keep a badge short and attach it to the item it qualifies. If the text conveys status, include the status in words and do not rely on color alone.

```html
<span>Pending review</span>
```

This is an app-level composition recipe; it does not add a component to UIify.
