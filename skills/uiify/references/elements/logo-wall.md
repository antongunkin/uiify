# logo-wall

Binding: gap

Show organizations associated with a product or event.

Give each meaningful organization logo an identifying alternative. If the adjacent text already names it, use an empty alternative to avoid repetition.

```html
<ul aria-label="Organizations using the product">
  <li><img src="/logos/acme.svg" width="120" height="40" alt="Acme" /></li>
</ul>
```

This is an app-level composition recipe; it does not add a component to UIify.
