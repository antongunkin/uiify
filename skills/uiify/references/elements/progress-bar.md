# progress-bar

Binding: gap

Show determinate completion of a task.

Give the progress value a visible label and range. Include text that explains completion when the visual meter is unavailable.

```html
<label for="upload-progress">Upload</label>
<progress id="upload-progress" value="3" max="5">3 of 5</progress>
```

This is an app-level composition recipe; it does not add a component to UIify.
