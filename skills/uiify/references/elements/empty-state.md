# empty-state

Binding: gap

Explain why a collection has no items and offer a relevant next step.

Explain what is empty and why it matters, then offer one next action that addresses the empty state.

```html
<section aria-labelledby="empty-title">
  <h2 id="empty-title">No invoices yet</h2>
  <p>Create an invoice to see it listed here.</p>
  <a href="/invoices/new">Create invoice</a>
</section>
```

This is an app-level composition recipe; it does not add a component to UIify.
