# header

Binding: header

Orient visitors with stable top-level navigation.

Use the header for the site identity and primary navigation. Keep repeated navigation in a consistent order and give each navigation landmark a distinct name when there are several.

Related laws: references/laws/readability.md, references/laws/accessibility.md
