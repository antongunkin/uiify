# stats-bar

Binding: gap

Summarize a few named values for one subject or time period.

Pair each metric with a clear label and value. Use a description list when the content consists of term-and-value pairs.

```html
<dl>
  <div><dt>Active users</dt><dd>1,248</dd></div>
  <div><dt>Period</dt><dd>Last 30 days</dd></div>
</dl>
```

This is an app-level composition recipe; it does not add a component to UIify.
