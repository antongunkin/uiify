# inline-alert

Binding: gap

Give a short message context beside the content it affects.

Use a status announcement for non-urgent updates and an alert only for information requiring immediate attention. Keep the message visible in context.

```html
<p role="status">Changes saved.</p>
```

This is an app-level composition recipe; it does not add a component to UIify.
