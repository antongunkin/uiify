# avatar

Binding: gap

Identify a person or account with a compact image and fallback.

When text beside the image already identifies the person, use an empty alt value; otherwise write a concise alternative that identifies the person without repeating nearby text.

```html
<img src="/people/ada.webp" width="40" height="40" alt="" />
<span>Ada Lovelace</span>
```

The empty alternative is appropriate here because the adjacent text already names the person.
