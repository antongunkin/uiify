# date-picker

Binding: gap

Collect one calendar date using the native date control.

Prefer the native date input for one date. Show date constraints in text and connect invalid-value feedback to the input.

```html
<label for="start-date">Start date</label>
<input id="start-date" name="start-date" type="date" />
```

This is an app-level composition recipe; it does not add a component to UIify.
