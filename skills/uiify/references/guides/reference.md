# Compare against a visual reference

Use this guide only when matching a supplied screenshot or comparing an existing page. Keep the requested scope: a reference is evidence for the requested work, not permission to redesign unrelated parts.

Compare the same route at the same viewport, the same state and the same scale. Note the page's grid and proportions, text roles, spacing rhythm, color roles, section order, image role and crop. Separate observed differences from assumptions; keep the notes concise and actionable.

Inspect project assets before choosing replacements. Use local assets such as images and fonts when available, and preserve recognizable content and crop where the reference calls for it. Do not invent an asset, brand detail or unavailable content. A mobile adaptation inferred from a desktop screenshot is not verified until checked at a real narrow viewport.

If the reference cannot be opened, continue with the accessible request and existing project. Say that visual fidelity could not be checked; do not claim to have inspected an unavailable image.
