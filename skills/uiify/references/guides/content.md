# Does the copy say what this page and each action actually do?

Read the page at its default viewport and in its relevant form or overlay states. Check that:

- Headings identify the subject or decision on this page, not a generic slogan. A settings page should name the setting group; a pricing page should name the offer.
- Action labels name the result. “Save changes” tells the user more than “Submit”; verify the label still fits at 390×844.
- An automatically detected input error identifies what happened and, when known, how to correct it. This follows [WCAG 2.2 Success Criterion 3.3.3](https://www.w3.org/WAI/WCAG22/Understanding/error-suggestion.html); do not invent a correction when the cause is unknown.
- Example content is plausible for the page and its audience. Replace lorem ipsum and repeated placeholder values, then inspect the populated state for wrapping and density.
- One term names one concept throughout the page. Compare navigation, headings, controls, confirmation, and errors for competing labels.

Use a real task sentence and realistic values to test the copy. If the same label could describe several different outcomes, make the result explicit.
