UIify 0.1.0-alpha is the first alpha with the coding-agent workflow: a PM writes a brief, the agent builds
three designs from your design system, you compare them in a preview and ship one by changing one line.
It works next to shadcn/ui and your own components. Changes since 0.0.31-alpha.

Try it: paste the prompt from the [README](https://github.com/antongunkin/uiify#try-it-with-your-coding-agent)
into your coding agent. Tested with Claude Code on Next.js and Vite.

## What's new

- **Features with several designs.** A feature folder keeps its slots in `contract.ts`, its designs in
  `designs/`, sample content in `sample.tsx` and the design the product uses in `active.ts`. Switching
  designs changes one import.
- **Guides for the agent** in `skills/uiify/references/guides/`: `feature.md` for the PM (brief, three
  designs, preview, choice) and `feature-dev.md` for the developer (connect, change the contract, ship);
  `preview.md` (Next.js App Router) and `preview-vite.md` (Vite) for a development-only preview of all
  designs. The role comes from the request or a `uiify role: pm` line in your own instructions.
- **`check-screens.mjs`** now also checks designs against their contract (`design-default`,
  `design-contract-type`, `design-destructure`, `design-rest`, `design-missing-slot`,
  `design-empty-wrapper`, `design-slot-in-text`), that `active.ts` imports exactly one design
  (`active-direct-import`), raw colors in any attribute, and project components with a UIify name
  (`screen-uiify-twin`).
- **Your own components in screens.** List their modules in `package.json`
  (`"uiify": { "components": ["@/components/ui/chart"] }`); `sync-agents.mjs --write` adds a "Project
  components" section to `AGENTS.md` and the check accepts their imports.
- **shadcn/ui compatibility.** Importing UIify no longer changes your app's Tailwind scale; the `dark`
  class switches UIify's dark values; with the Tailwind adapter UIify controls have the size of shadcn's
  default "nova" style and read shadcn's own variables (`--spacing`, `--radius`, `--text-*`,
  `--primary`). UIify defines no `--control-*` variables any more: change those shadcn/Tailwind values
  instead. `check-screens` rejects UIify's internal variables and selectors in screens and project CSS
  (`screen-uiify-var`, `screen-uiify-selector`, `css-uiify-var`, `css-uiify-selector`).
- **`sync-agents.mjs`** no longer writes a second catalog section into a `CLAUDE.md` that imports
  `AGENTS.md` with an `@AGENTS.md` line.
- **Focus** is a solid 2px outline in the `--ring` color, visible in both themes (5.9–6.6:1 against the
  background) and in forced-colors mode.

## Breaking changes

- **shadcn names for flat roots:**
  - Breadcrumb: `BreadcrumbRoot` → `Breadcrumb`; new `BreadcrumbPage`; `BreadcrumbEllipsis` is the part
    itself.
  - Table: `TableRoot` → `Table`, `TableColumnHeader` → `TableHead` (class `uiify-table-head`).
  - Toast: `ToastRoot` → `Toast`. Tooltip: `TooltipRoot` → `Tooltip`. Header: `HeaderRootProps` →
    `HeaderProps`.
  - Drawer: the native parts are `Drawer`, `DrawerTrigger`, `DrawerClose`, `DrawerContent`, with
    `DrawerHeader`, `DrawerBody`, `DrawerFooter` and `DrawerGrabber` (were `DrawerNative*`); the client
    drawer moved to `@gunkin/uiify/components/drawer/client` with `DrawerClient*` types.
  - Props types follow the names (`TableRootProps` → `TableProps`, and so on).
- **Defaults like shadcn:** `Badge` without a variant uses the primary color; `Button variant="destructive"`
  is a tinted background with destructive text.
- **Focus ring:** the focus style moved from a translucent `box-shadow` ring to `outline`. If you restyle
  focus with `className`, check that you do not now get both.
- **Screen check:** existing feature folders may get new findings from the rules above. With TypeScript 7,
  install `@typescript/typescript6` next to it; the check needs its parser API.

## Known limits

- Tested with Claude Code only; agents that read `AGENTS.md`, such as Codex, are not tested yet.
- Needs React 19.3 or later; UIify's look needs Tailwind CSS 4.1 or later.
- The JSON document layer (`@gunkin/uiify/ai`) is frozen: kept working, not growing.
